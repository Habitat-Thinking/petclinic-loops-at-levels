# Level 5 solo — 20 minutes. Beats for ./bin/demo run sentinels
# Pairs with sentinels/slides/LEVEL-5.md (18 slides).
#
# THE SPINE, and every beat serves it:
#
#   A habitat has two jobs. It supports the AGENTS - through the harness, the
#   constraints, the pipeline, the gates. And it supports the HUMAN - through
#   the sentinels, which protect decision sovereignty and the capability to
#   keep exercising it.
#
#   Act 1 (beats 2-5) is the first job, EXPLAINED.
#   Act 2 (beats 6-12) is the second job, SAMPLED.
#
# NOTHING DISPATCHES AN AGENT. Every sentinel beat plays a committed sample to
# the terminal. No profile, no login, no --plugin-dir, nothing that can wander.
# The deck leads each one by naming the CHARACTERISTIC; the terminal then shows
# that characteristic in the instrument's own words.
#
# The samples are real, unedited output from real runs, and they are samples
# because all four live does not fit:
#   mast 46s / reservoir 65s / wip 121s / cost-estimator 289s = 8m41s of
#   dispatch alone, in a twenty-minute slot. What makes them worth showing is
#   the REASONING, which a sample preserves perfectly.
#
# ONE THING IS STILL LIVE: beat 3, a shell script. Deterministic, two seconds,
# and it is there because the Level 3 argument rests on the harness being real
# rather than described.
#
# Cut order: beat 5, then 8, then 3, then 12. Beats 13-16 are THE CLOSE and
# never cut. Beat 1 never cuts - it is the thesis, and without it this is a
# tour of a plugin.
