# Cost Snapshot — 2026-09-20

First snapshot for this repository. It covers one thing precisely: the Level 4
pipeline run, from the first `/carpaccio` dispatch at 18:02 on 2026-09-19 to the
integration gate closing at 12:48 on 2026-09-20.

**Two figures, because only one of them is money that moved.** Claude Code ran on a
Max subscription, which is not metered per token, so the marginal cash cost of this
run was **£0.00**. The API list-price equivalent of the same work is **~$211**. Both
are recorded below; neither alone is honest.

### Where the cost actually is

| Component | Tokens | List cost | Share |
| --- | --- | --- | --- |
| Output | 894,918 | $22.37 | 11% |
| Cache writes | 13,749,531 (6.9M @ 5-min TTL, 6.8M @ 1-hour) | $111.47 | 53% |
| Cache reads | 154,373,847 | $77.19 | 37% |
| Uncached input | 2,494 | $0.01 | ~0% |

Rates: Opus 5 at $5/MTok input, $25/MTok output, cache writes at 1.25× (5-min) and
2× (1-hour), cache reads at 0.1×.

**The output tokens — the part anyone would call "the work" — are 11% of the bill.**
The other 89% is context being written to cache and read back, twenty dispatches deep,
each agent re-reading an accumulating pile of records. That is the cost shape of an
agentic pipeline, and it is invisible from the agent-by-agent token counts the
harness reports.

## Observations

- **A previously published figure was wrong by two orders of magnitude.** The run was
  first recorded as "~1.4M tokens", taken from the per-agent counts in task
  notifications. The true total is **169M**. Those notifications do not count cache
  reads, which are 91% of the tokens. The slide deck, run sheet and findings have been
  corrected.
- **Cost is dominated by re-reading, not by producing.** See the table above.
- **The routing table is untested.** Every dispatch ran on Opus 5 regardless of what
  `MODEL_ROUTING.md` says, because the driving session's model is fixed. No routing
  change is proposed on this evidence — the evidence does not exist yet.
- **Operational risk, unrelated to cost but found while capturing it:** the Max plan
  renews on 2026-09-29 with **no payment card on file** ("Upcoming payments need a
  credit or debit card saved to this account"). If that renewal fails, the demo
  profile loses its Max capability before the talk.
